## Week goals

| Week | Theme | Focus |
| --- | --- | --- |
| 1 | Creative Development | Purpose, collaboration, iteration (Big Idea 1) |
| 2 | Data | Bits, abstraction, compression, bias (Big Idea 2) |
| 3 | Programming I | Variables, strings, conditionals |
| 4 | Programming II | Iteration, lists, traversal |
| 5 | Programming III | Procedures, algorithms, efficiency |
| 6 | Systems & Networks | Fault tolerance, packets, HTTPS (Big Idea 4) |
| 7 | Impact of Computing | Equity, IP, privacy (Big Idea 5) |
| 8 | Create PT & Exams | Studio + practice/final exams |

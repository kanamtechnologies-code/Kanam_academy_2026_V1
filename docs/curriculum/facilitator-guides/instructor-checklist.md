# Instructor session checklist

Use before each observed or scored session. Pair with a [facilitator guide](README.md) and, for finals, a [capstone rubric](rubrics/).

## Before class (10 min)

- [ ] Lesson / track confirmed; students can reach the lesson URL
- [ ] Sample run works in the workspace (SQL or Python)
- [ ] Warm-up + CFU questions skimmed (coach notes / `cfu` in lesson)
- [ ] Accessibility: captions, font size, seating for vision/hearing needs
- [ ] Privacy: demo data only; no live student PII in shared screens

## During class

- [ ] Warm-up connects to prior lesson (2–5 min)
- [ ] Teach → guided practice → independent exercises visible
- [ ] CFU used mid- or end-of-session (oral or written)
- [ ] Stuck students get a prompt, not a pasted answer
- [ ] Close: 1 takeaway + next step

## After class (5 min)

- [ ] Note 1 misconception for next session
- [ ] Log PD/observation hours if this was a coaching visit → [pd-hours-log.md](pd-hours-log.md)
- [ ] Capstone week: attach rubric scores → [rubrics/](rubrics/)

## Observation-ready evidence pack

1. Printed session guide  
2. This checklist (checked)  
3. 1–2 anonymized student work samples  
4. CFU or rubric scores  
5. Standards codes from track docs

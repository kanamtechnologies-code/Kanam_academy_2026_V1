# Rubric — Data Analyst Capstone (Lesson 14)

**Purpose:** Score an end-to-end investigation: question → query → evidence → honest conclusion.  
**Standards anchors:** CSTA `3A-DA-11`, `3A-DA-12`, `2-DA-09`; Draft `MS-DAA-27`; Cognia STEM Provider Std 9.  
**Evidence:** Working SQL + chart (or ranked table) + 2–3 sentence reflection (question, method, limitation).

| Criterion | Emerging | Developing | Proficient | Advanced |
| --- | --- | --- | --- | --- |
| **Investigative question** | Vague or missing | Question stated but hard to measure | Clear, answerable question (who/what + measure) | Question + why it matters; success criteria named |
| **Method (SQL steps)** | Random queries; no join/agg when needed | Partial pipeline (explore only or broken join) | Explore → join (if needed) → aggregate → rank | Pipeline is intentional; student can justify each step |
| **Result accuracy** | Wrong or empty answer | Close but key filter/join error | Ranked/summarized result matches the question | Result checked against a second query or sanity sample |
| **Visualization / presentation** | No chart or unrelated display | Chart present but hard to read | Chart/table matches the claim (labels + numbers) | Sort/labels make the story obvious; chart type fits |
| **Conclusion & limits** | Opinion only | States answer without data link | One-sentence answer backed by the result + one limitation | Names limitation + ethics/privacy note when analyzing people |
| **Ethics / privacy** | Ignores sensitive fields | Mentions privacy only if prompted | Notes why person-level data needs care | Suggests a safer real-world practice (consent, minimize IDs) |

**Mastery bar (Proficient+):** Correct ranked answer to “who spent the most?” (or equivalent site question), chart or clear table, and a limitation stated in the student’s own words.

**Showcase session:** Use Session 2 (celebrate) for oral demos; score written evidence from Lesson 14 + reflection even if the oral demo is brief.

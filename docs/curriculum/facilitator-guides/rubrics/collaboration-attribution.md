# Rubric — Collaboration & attribution (paired work)

**Purpose:** Document fair collaboration and credit for help/AI — supports CSTA **`2-AP-16`** and Cognia Std 9.  
**Use with:** Any paired lab, Python Weeks 7–8, or Data showcase teams.

| Criterion | Emerging | Developing | Proficient | Advanced |
| --- | --- | --- | --- | --- |
| **Roles** | One student does almost all work | Roles claimed but uneven | Both contribute (driver/navigator or split tasks) | Roles rotate; both can explain the whole solution |
| **Communication** | Little discussion | Talks over / silent partner | Shares ideas; listens; asks clarifying questions | Resolves disagreements with evidence (run output, plan) |
| **Attribution** | No credit for help/AI | Vague “we used AI” | Names what help/AI provided vs. what the pair wrote | Clear changelog: human decisions + tool suggestions |
| **Integrity** | Submits work they cannot explain | Explains only their half | Each student can walk through the submitted solution | Can teach a peer the key idea without reading the code line-by-line |

**Quick protocol (5 minutes):** Before submit — (1) Who drove? (2) What did each person write? (3) What did a tool suggest? (4) One thing we’d change next time.

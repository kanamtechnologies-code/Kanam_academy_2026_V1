# Rubric — Python & AI Foundations Capstone

**Purpose:** Score a complete student program that solves a stated problem and demonstrates core Python skills from the track.  
**Standards anchors:** CSTA `2-AP-13`, `2-AP-17`, `2-AP-19`; Cognia STEM Provider Std 9.  
**Evidence:** Working code + short demo + 2–3 sentence reflection.

| Criterion | Emerging | Developing | Proficient | Advanced |
| --- | --- | --- | --- | --- |
| **Problem & plan** | Goal unclear; no plan | Goal stated; plan incomplete | Clear goal + steps that match the build | Goal, constraints, and success check defined before coding |
| **Code correctness** | Does not run / major errors | Runs with help; partial result | Meets stated requirements without coach edits | Meets requirements + sensible edge-case handling |
| **Core skills used** | Uses few track concepts | Uses some (vars, I/O, or conditionals) | Uses multiple track skills appropriately (e.g. loops + functions or data structures) | Chooses structures that fit the problem; code is readable |
| **Testing & debugging** | Relies on coach to fix | Tries Run; limited diagnosis | Uses Run/output to find and fix own bugs | Explains what failed and how they verified the fix |
| **Communication** | Cannot explain the program | Explains parts with prompts | Demo: what it does, how it works, one limitation | Clear demo + reflection on tradeoffs / next improvement |
| **Responsible use** | Ignores safety/attribution | Mentions AI/help vaguely | Credits help/AI; owns the logic they submit | Explains what they wrote vs. what tools suggested |

**Mastery bar (Proficient+):** Program runs, matches the plan, student can demo and name one limitation without reading every line for them.

**Facilitator notes:** Score the *learning evidence*, not polish. Partial credit across criteria is fine. Pair with [collaboration-attribution.md](collaboration-attribution.md) if students worked in pairs.
